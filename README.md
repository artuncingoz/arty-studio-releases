# Arty Studio

Downloads and updates for **Arty Studio**, the AI video and image studio for your desktop.

- **Download:** open [the latest release](https://github.com/artuncingoz/arty-studio-releases/releases/latest) and pick the file for your computer:
  - Mac with Apple Silicon (M1 or later): `Arty-Studio-<version>-arm64.dmg`
  - Mac with Intel: `Arty-Studio-<version>-x64.dmg`
  - Windows: `Arty-Studio-Setup-<version>-x64.exe`
- **First launch:**
  - **Mac:** open the .dmg, drag Arty Studio into Applications and open it. If macOS says it can't check the app, go to System Settings → Privacy & Security and click **Open Anyway** next to Arty Studio. You only do this once.
  - **Windows:** if SmartScreen appears, click **More info** → **Run anyway**.
  - These warnings show until the app's signing certificates are in place. Only download Arty Studio from this page or [artydigital.com.tr/arty-studio](https://www.artydigital.com.tr/arty-studio).
- **Updates:** the app checks this page by itself and tells you when a new version is out.
- **License:** buy a plan at [artydigital.com.tr/arty-studio](https://www.artydigital.com.tr/arty-studio); the key comes by email.
- **Support:** info@artydigital.com.tr

This repository only hosts the installers. The FFmpeg (LGPL) and libvips source archives the app uses are attached to every release.
